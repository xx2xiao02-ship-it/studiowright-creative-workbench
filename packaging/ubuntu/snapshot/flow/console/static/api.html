1. 地址和登录方式

当前调用地址：http://127.0.0.1:18888

Windows 通过 SSH 转发连接 Ubuntu；Ubuntu 本机也使用 http://127.0.0.1:18888。其他电脑调用前，需要建立相同的 SSH 转发。当前服务不接受直接用局域网 IP 访问，18889 是模拟环境端口。

这是本后台的任务 API，不是 OpenAI 兼容接口，不使用 /v1/chat/completions。插件的连接 Token 也不能替代 API 登录。

浏览器可继续使用登录会话；外部项目建议在下方创建独立 API Key，无须浏览器登录。旧的会话接入方式仍可使用：调用程序先用一次性连接码换取登录会话；连接码 5 分钟内有效、只能用一次，会话最长 7 天。退出会话后需重新连接。浏览器已登录，不代表另一个调用程序也已登录。

素材库接入 · Flow2API 七维标签
标签分类与原库一致：subject 主体、scene 场景、action 动作、style 风格、camera 镜头、color 色调、keywords 关键词。不同维度按 AND 组合，每个维度精确匹配、不区分英文大小写；未填维度不限制。q 是提示词或任意标签的包含查询。标签来源见 tag_sources：prompt_analysis 为提示词整理，visual_analysis 为实际画面识别，manual 为人工编辑。observed_tags 仅包含画面识别标签；未进行画面识别时为空。视频识别只覆盖按时间抽样的帧，不含音频，不能代表逐帧核验。人工编辑的维度优先且不会被自动覆盖。
GET /api/library 保留当前结构：tags 是自定义标签数组，structured_tags 是七维对象。兼容入口 GET /api/material-library/assets 使用原格式：tags 是七维对象、custom_tags 是普通标签。资产 ID 使用新库文件哈希，原库 ID 在 origins.source_id；不能把旧 ID 直接当作新 ID。相同文件可以有多个来源，origins 全部保留。账号、项目、模型、日期条件必须在同一条来源记录上满足。
参数含义 / 范围
q最多 500 字；包含匹配提示词、模型、项目、邮箱、素材编号或任意标签。
subject / scene / action / style / camera / color / keywords每个最多 100 字，可同时组合；标签候选及素材数量从 /api/library/facets 的 dimensions 读取。
kind / media_typeimage 或 video；当前入口用 kind，兼容入口用 media_type。
tag / account当前入口的普通标签 / 来源邮箱或 source:account_id。
model / project_id / account_id原生成模型 ID / 完整原项目 ID / 原来源账号 ID，精确匹配。
created_from / created_to按原记录日期闭区间查询，YYYY-MM-DD；不按文件复制日期。原库没有记录时间时不能匹配。
index_statuspending / processing / ready / failed；手动标签可在任意分析状态下使用。
storage_status新库只返回已保存文件 ready；排队保存情况见 pending / errors，其他保存状态查询返回空列表。
limit / offset / pagelimit 1～100，当前默认 24、兼容默认 30；offset ≥0，有 offset 时优先；当前入口也支持 page（从 1 开始）。按入库时间倒序、ID 稳定分页。
GET /api/library/facets 和 GET /api/material-library/facets 返回 counts、七类 dimensions（每项 value、count）。GET /api/library/{id} 返回完整标签、标签来源和全部原始来源；GET /api/library/{id}/file 下载原文件，GET /api/library/{id}/thumbnail 读取图片缩略图。兼容详情与文件入口分别为 /api/material-library/assets/{id} 和 /api/material-library/assets/{id}/file。
请求文件也必须在请求头携带密钥，不要把密钥拼进 URL。没有跨站浏览器 CORS 开放，其他项目通过服务端或当前 SSH 转发调用；127.0.0.1 指调用程序所在电脑。标签自动分析默认关闭，可在素材库“自动标签设置”配置主备模型并明确启用；该操作可能产生模型费用。分析失败保留文件与手动标签，最多自动尝试三轮，可在详情重试。

3. 常用接口
接口用途是否提交生成


GET /health服务是否启动；无须登录否
POST /api/auth/connect用连接码建立会话否
GET /api/state账号、项目、模型、最近 150 条任务否，只读本地记录
POST /api/tasks检查、报价、读取素材或提交生成，由 kind 决定image / video 会提交
POST /api/tasks/{任务ID}/cancel只取消尚未开始的排队任务不能撤销已开始的生成
GET /api/tasks/{任务ID}/files/{序号}下载成功任务的文件；序号从 0 开始否
GET /api/library检索素材库，支持七维组合、关键词、模型、项目、日期与分页，详见素材库章节否
GET /api/library/{素材ID}/file读取原文件；加 ?download=1 下载否
POST /api/logout退出当前 API 会话，不退出 Google 账号否


除健康检查和登录换码外，业务接口使用会话 Cookie 或有相应权限的 API Key。登录窗口、密钥管理、账号配置和标签修改仅限后台登录会话。POST 请求还需 Content-Type: application/json 和 X-Console-Request: 1。这是后台本身的要求，不能省略。

6. 查询、重试与下载
保存提交返回的 id，用 GET /api/tasks/{id} 查询最新状态和下载路径。queued 排队、running 执行中、succeeded 成功、failed 失败、interrupted 中断、cancelled 排队时取消。
单图确认失败后，通过 POST /api/tasks/{原任务编号}/retry 补跑。请求体 {"expected_ordinal":0,"confirm_generation":true} 中的序号取最近一次已核对尝试的 ordinal，首次为 0。补跑可能消耗积分，同一序号重复提交只补跑一次。查询和下载继续沿用原任务编号。

7. 常见返回与排查
返回处理方式
202仅表示排队成功，继续查任务状态。
400读取 error 字段，检查账号、项目归属、模型参数、生成确认与提交编号。
401调用程序未登录或会话到期，重新获取连接码并兑换会话。
403检查请求地址、两个 POST 请求头；浏览器跨站调用受限制，建议用服务端程序或 SSH 转发。
409任务已开始或已结束，不能取消；查询原任务，不重新生成。
任务 failed / interrupted查看该任务 error 和 result.source_jobs，先核对原执行结果，避免重复扣积分。
