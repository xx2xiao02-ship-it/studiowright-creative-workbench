插件安装指引
  1. 勾选账号，点「安装 / 重载插件」，打开对应的扩展管理页。
  2. 首次安装时开启「开发者模式」，点「加载已解压的扩展程序」，选择下方文件夹。已安装时，找到对应插件并点「重新加载」。
  3. 在对应 Flow 窗口登录后，回到此页点「同步所选账号」。最终以「Ubuntu 登录核对成功」为准。

列表只读取 Chrome 名称、邮箱和插件登记信息。实际 Flow 登录账号以 Ubuntu 核对结果为准。同步不会创建项目、生成素材或消耗积分。
