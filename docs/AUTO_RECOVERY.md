# 自动恢复

普通故障由程序主动复查和恢复，明确的审核、风控和冷却限制保留原因，不自动解除。

- Ubuntu 工作台每分钟巡检一次，不依赖界面保持打开。后台共享恢复锁，同一实例五分钟内不重复启动恢复。
- 账号页和总览发现窗口绑定、窗口数量、项目加载失败、输入框、已识别提示层或临时状态异常时，也可触发恢复入口 `/api/flow-readiness/auto`。
- 已登记项目的空闲账号遇到连接或页面问题时，先重新连接、恢复原项目页并复查。账号卡显示「自动恢复中」，成功后恢复就绪，连续三次未恢复才提示人工处理。明确的 Google 登录或验证要求直接提示。
- 复用已登记账号和现有项目。受原生进程、唯一任务窗口、账号身份、空闲状态和空草稿检查约束；修复失败保留原因并等待下次有界尝试。
- 非运行中的受管浏览器可以按既有流程重新打开；只有已核对为安全的连接故障才允许既有重启路径。
- 保留已绑定的任务页。确认同账号、无草稿、无附件、无运行任务后，可以关闭多余的空 Flow 首页和同项目空副本。页面恢复后会重新读取已过期的积分。
- 后台发现草稿或附件时暂停派发，保留未提交内容。手动点「Flow 一键就绪」会刷新空闲的原任务页，清除未提交草稿和挂载素材，然后复查。登录验证和风控继续由用户核对。
- 普通恢复不创建生成请求。若生成超时后已查询原项目且未发现新图片，按失败结束本地显示；同时核验原始失败记录无素材/文件、账号匹配且无活动任务后，允许解除该原任务的窗口占用。保留原编号及提交去重，不自动重发。普通网络超时、尚未执行结果查询或已有素材证据，不适用这一处理。
- 正常运行任务占用账号时显示需排队；失败或中断的关联任务显示实际错误，无错误详情则标注待核对。
- 窗口被占用、暂时找不到关联任务时先复查。确认原任务页已空闲后才刷新。占用持续且无法确认空闲的页面会提示核对。
- 账号、项目、记录和总览页在无草稿、无上传和无修改中设置时允许加载新版界面；编辑中的工作台保留现场。

运行状态位于快照 `keepalive_monitor.flow_auto_recovery`，含最近完成时间、状态和采取动作的账号数量。界面恢复期间显示“自动修复中”，恢复后复查状态。

## 报错处理对照表

| 提示或现象 | 当前处理 |
| --- | --- |
| Flow 显示窗口占用 | 查到关联任务时显示处理中和任务编号。暂时查不到任务时先复查，确认原页空闲后刷新一次。刷新后仍异常，或仍无法确认空闲时，提示核对。 |
| Flow 原项目页加载失败、出现重复窗口或积分过期 | 优先恢复已绑定的原项目页。确认同账号后才关闭空首页或同项目空副本。页面恢复后重新读取过期积分。 |
| Flow 页面有草稿或挂载素材 | 后台保留未提交内容。手动点「Flow 一键就绪」可刷新空闲原页并清理未提交内容。正在生成或远程登录的窗口会跳过。 |
| Flow 被要求重新登录或完成 Google 验证 | 工作台提示「需要用户登录」。在该账号的 Ubuntu 浏览器完成后，回原项目复查。 |
| Flow 浏览器扩展自检未通过 | 保留具体拦截原因。确认扩展已停用后，清理该账号浏览器中的旧扩展或残留，再复查。 |
| Flow 参考图上传遇到使用权弹窗 | 只在识别到标准弹窗且明确匹配一个同意按钮时自动确认。遇到无法确认的弹窗，保留截图和失败原因。确认生成尚未提交时，符合条件的单份生成任务可按原编号排队切号重试。 |
| Flow 返回「异常活动」 | 确认错误码 7 后，生成账号至少冷却 15 分钟，原任务停止自动重试。连续两次错误码 7 会暂停派发并记录告警。其他异常活动沿用 30 分钟冷却，连续三次异常活动的暂停保护仍有效。核查后点「已核查，恢复 Flow」，未到期的冷却仍然有效。 |
| 手动暂停 Flow 账号 | 在「账号操作」使用「暂停账号」和「恢复账号」。暂停期间停止该账号的生成派发、自动切号重试和保活。窗口正在执行或远程登录时，等空闲后再暂停。恢复账号只解除手动暂停，继续遵守风控核查和冷却。 |
| Flow 生成已提交，结果还无法确认 | 保留原任务编号和核对记录。查询原项目、核实已有素材与文件后再处理。 |
| Gemini 额度不足或频率受限 | 账号停派并等待官方额度更新。5 小时及每周额度都有余额后，后台用原账号复查。复查通过后恢复派单。复查失败至少等 15 分钟，并取得新的额度读数后再查。 |
| Gemini 首次建立识图或视频抽帧会话超时 | 确认图片尚未发送时，用原账号和原请求编号补试一次。 |
| Gemini 返回容量不足、已有部分回复或结果待核对 | 明确收到容量不足回执且整次没有回复时，原账号按 10 秒、30 秒间隔最多补试两次。已有部分回复或结果待核对时，查询原编号。请求传 `retry_policy: "never"` 可禁止自动重试。 |

Gemini 的请求字段、判断条件和查询方式见 [API 文档](API.md)。
